How the angles are defined (all measured from a square cut, i.e. 0° = straight through the board):

  • Long-side bevel B — tilt the saw blade this much for the rip cut along each of the two long edges, so neighboring boards close up into the polygon. B = 90° − Φ/2.
  • End bevel β — tilt for the top and bottom cuts so the rim and base sit level. β = atan((a₂−a₁)/h).
  • Side taper δ — in-plane angle of the long edges when you mark the trapezoid on the board face.
